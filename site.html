Proposal vs. Existing Facilities

Do communities restrict because of data centers already operating nearby, or because of new proposals? We tested both:

  • Operating sites alone: -1% per doubling (p=0.92) — not significant
  • Proposals alone: +63% per doubling (p<0.001) — highly significant
  • Both together: Proposals stay significant, operating sites remain near zero

Conclusion: Restrictions respond to future proposals, not past infrastructure. Towns restrict when they hear about a new project nearby, not when data centers already exist.

State-Level Correlation

Across 50 states, we find:

  • Operating vs. Restrictions: Spearman ρ = 0.54 (moderate positive)
  • Proposals vs. Restrictions: Spearman ρ = 0.67 (strong positive)
  • Interpretation: States with more proposals have significantly more restrictions

⚠ Caveat: These are associations among 50 states, not proof of causation. Texas and Virginia are outliers with more restrictions than the model predicts, possibly due to data gaps or unique state policies.

Data Limitations & Outliers

Important notes on the data:

  • Missing operating sites: FracTracker lists zero facilities in Florida, Kansas, and Utah — likely a data gap, not the true count
  • Incomplete capacity: Most operating data centers have no megawatt figure reported
  • Proposal completeness: FracTracker is still filling in its proposals list
  • Policy gaps: Some local actions may not be documented in the Policy Database
  • Timing: This snapshot is current through November 22, 2026

What it means: The 60% / 48% finding is conservative. True proposal-first correlation is likely higher, and state-level effects may be understated where data is missing.

Methods

  • Distance analysis: Haversine distance from each restriction to nearest operating data center
  • Hub definition: Single-linkage clustering of sites within 25 miles; "big hub" = 12+ sites
  • Proposal-first test: For restrictions since mid-2024, % with FracTracker proposal within 25 miles before the restriction date
  • Random baseline: Same test on random GeoNames towns (1000+ residents), same date range
  • State regression: Negative binomial model: restrictions ~ log₂(1 + operating) + log₂(1 + proposed)

Behind the Atlas

How Claude built this site

This site was built by Claude AI from instructions and two public data sources. Here's how it was made and how you can rebuild it with updated data.

Data sources

  1. Operating data centers: FracTracker Alliance tracks 536 operating facilities with location, operator, capacity class, and community feedback.
  2. Local restrictions: The Data Center Policy Database (Bridges et al., 2026) documents 469 moratoria, bans, and zoning rules passed locally through November 2026.
  3. Maps: us-atlas provides pre-projected county and state boundaries (TopoJSON format).

Building process

  1. Data validation: Read both sources, counted records by type and status, flagged missing values.
  2. Local restrictions map (Page 2): Built a county choropleth colored by strongest policy (ban > moratorium > zoning). Added filters, state table, and policy list in side panel.
  3. Operating data centers map (Page 1): Built symbol map with sized dots for each facility, orange for pushback, dashed outlines for low-confidence locations. Added state table with capacity data.
  4. Combine into one site: Added tab navigation to let readers flip between pages. Each page maintains its own filters and scroll position.
  5. Documentation: This page explaining sources and methods, so the work is transparent and reproducible.

Key decisions

  • Local policies only: Focus on city/town/county action, not federal or state bills, because grassroots resistance lives at the local level.
  • Three types of action: Moratoria (time-limited pauses), bans (prohibitions), and zoning rules (land-use limits). Some zoning rules allow data centers in certain zones; others restrict them. The database lumps both together.
  • Expired moratoria: Shown in lighter gray, can be hidden with checkbox. Readers often want to see only current restrictions.
  • All location confidence levels: Operating data center locations come in High, Medium, Low. The map shows all of them; dashed outlines indicate low confidence, so uncertainty is visible rather than hidden.

Rebuilding this site

To update with new data or adapt for another state/country:

  1. Download latest FracTracker data (Google Sheet export or CSV)
  2. Download latest policies export (CSV)
  3. Open this site's folder in Claude Code (desktop app)
  4. Upload both files and ask Claude: "Rebuild the site with this new data, update all the numbers and facts, and republish."
  5. Publish to a new Claude artifact or push to GitHub Pages
