Behind the Atlas

How Claude built this site

This site was built by Claude AI from instructions and data sources. This page explains where the data comes from, how it was processed, and what it shows.

1. Data sources

  1. Operating data centers: FracTracker Alliance's public data center tracker, with 536 operating facilities, their locations, operators, size classes, and capacity in megawatts. fractracker.org/data-centers
  2. Local restrictions: The Data Center Policy Database (Bridges et al., 2026) with 469 local policies: moratoria, bans, and zoning rules passed by cities, towns, townships and counties. datacenterpolicy.com
  3. Maps: U.S. Census-based county and state boundaries from us-atlas, pre-projected for Alaska and Hawaii placement.

2. Building process

The site was built by Claude AI through an iterative conversation. Each section below describes one stage:

  1. Data validation: Read the raw data sources, counted records by status and type, flagged any errors or missing values.
  2. Local restrictions map (Page 2): Built a county choropleth map, colored by policy type. Counties with bans show in red, moratoria in blue, and zoning rules in yellow. Added filters and a side panel to show which policies passed where.
  3. Operating data centers map (Page 1): Built a symbol map showing each operating facility as a sized dot. Orange dots indicate community pushback; blue dots have none reported. Dashed outlines show low-confidence locations.
  4. Combine into one site: Added tab navigation to let readers flip between the two maps without losing their filters and selections.
  5. Add documentation: This page, explaining the sources and methods so the work is transparent and reproducible.

3. Key decisions

  • Local policies only: The site focuses on locally-enacted policies (cities, towns, counties), not state or federal bills, because local action is where grassroots resistance shows up.
  • Three types of action: Moratoria (time-limited pauses), bans (prohibitions), and zoning/siting rules (land-use limits). Some of the third type permit data centers in certain zones; others restrict them. All are lumped together because the source doesn't split them.
  • Expired moratoria: Shown in a lighter color and can be hidden with a checkbox, since readers often want to know what's currently in effect.
  • Confidence levels: Operating data center locations come in three confidence levels. The map shows all of them, using dashed outlines for low-confidence sites instead of hiding them, so readers see uncertainty rather than false precision.

4. Limitations and caveats

  • Undercounted operating sites: FracTracker says its list is still being filled in. It lists zero operating data centers in Florida, Kansas, and Utah — likely a data gap, not the true count.
  • Incomplete capacity data: Most operating data centers have no megawatt figure; some list only a range. The "Reported MW" column sums only single values, so it's a minimum.
  • Policy database gaps: The Data Center Policy Database is built by researchers at UVA and may miss policies that weren't publicly documented or weren't found during their search.
  • Snapshot in time: Both sources change weekly. Dates shown are as of November 2026.

5. Building this for yourself

To rebuild this site with updated data or fork it for another state or country:

  1. Download the latest FracTracker data and policies export
  2. Open this site's folder in Claude Code (the desktop app)
  3. Ask Claude to process the data and rebuild the pages with the new numbers
  4. Publish to a new Claude artifact or push to GitHub Pages
